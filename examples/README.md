# Eksempelfiler

`huginn-eksempel.csv` — fem fiktive leads til å teste import med. Fire nye
(ulike steg, én med e-postsamtykke, én med booket møte, én tapt) og én rad
som matcher eksempel-leaden Huginn selv legger inn, så du ser at den hoppes
over. Innstillinger → Importer → velg filen. Forventet melding:
«Importerte 4 nye leads, hoppet over 1 som fantes fra før».

Alle selskapsnavn, org.nr, personer og numre er oppdiktet.
